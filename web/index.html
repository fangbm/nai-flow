HOW IT WORKS
使用说明
  1. 先启动后端和前端，然后在“服务端连接设置”保存 NovelAI token；密钥不会返回给页面。
  2. 基础出图：主提示词写构图/动作/场景，角色栏固定角色外观；姿势和机位使用短 tag，叙事关系用句子。
  3. 本子工作流：输入梗概后获得可编辑分镜，按“生成本页”产出一张含多格版式的页面。
  4. 可选配置 OpenAI 兼容文本模型来生成剧本；没有它也可用本地分镜初稿。
V5 规则：不自动抄写质量预设；UC 留空即使用 NovelAI 默认预设，多人页面避免写 extra characters。
